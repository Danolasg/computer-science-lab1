# Лабораторная работа №1

## Анализ устройства современной информационной системы

### Цель работы

Получить представление об устройстве современных информационных систем на примере реального цифрового сервиса.

### Выбранный цифровой сервис

**Название:** Aviasales

**Вариант:** 7

**Ссылка:** https://www.aviasales.ru/

**Назначение:** сервис поиска авиабилетов.

**Выбранный сценарий:** поиск авиабилетов по маршруту.

### Результат

В работе проведён анализ информационной системы Aviasales. Исследованы основные компоненты пользовательского интерфейса и клиентской части, с помощью DevTools рассмотрено сетевое взаимодействие с API, описан пользовательский сценарий поиска авиабилетов и подготовлена архитектурная схема системы.

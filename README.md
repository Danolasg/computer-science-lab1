# Лабораторная работа №1

## Анализ устройства современной информационной системы

### Цель работы

Получить представление об устройстве современных информационных систем на примере реального цифрового сервиса.

### Выбранный цифровой сервис

**Название:** Т-Банк

**Вариант:** 9

**Ссылка:** https://www.tbank.ru/

**Назначение:** Финансовый цифровой сервис (экосистема банковских и цифровых продуктов).

**Выбранный сценарий:** Изучение публичных продуктов и формы заявки.

### Результат

В работе проведён анализ информационной системы Т-Банк. Исследованы основные компоненты пользовательского интерфейса и клиентской части, с помощью DevTools рассмотрено сетевое взаимодействие с API, описан пользовательский сценарий изучения продуктов и подачи заявки, а также подготовлена архитектурная схема системы.
